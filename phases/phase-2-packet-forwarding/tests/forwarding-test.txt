# Phase 2 – Packet Forwarding

In this phase, I first tried packet forwarding using Linux network namespaces. Later, I started working on connecting my mobile phone to my laptop using a Wi-Fi access point.

## 1. Network Namespace Setup

  I created three namespaces: `clientA`, `router` and `clientB`.

   I connected them using veth pairs and assigned IP addresses to create two different networks.

   After that, I enabled IPv4 forwarding and added routes on both clients.

   Iused ping to check whether the two clients could communicate through the router.

   The ping test showed 4 packets received with 0% packet loss.

   Commands and test details: `tests/namespace-forwarding-test.txt`

## 2. Wi-Fi Access Point Setup

   After trying the namespace method, I started working with a real Wi-Fi connection.

   I created a virtual Wi-Fi interface called `ap0` and used hostapd to start a Wi-Fi network named `VirtualRouter`.

   I assigned `192.168.50.1/24` to the `ap0` interface.

   My mobile phone could see the Wi-Fi network and complete the authentication, but it disconnected afterwards. So, a stable connection is still pending.

 Commands and test details: `tests/wifi-ap-test.txt`

## What is done 

- Created network namespaces and veth connections.
- Tested packet forwarding between two networks.
- Created the `ap0` Wi-Fi interface.
- Started the `VirtualRouter` Wi-Fi network using hostapd.
- Assigned an IP address to `ap0`.
- Tested connection from my mobile phone.
