# Phase 6 – Network and DNS Logging

## What I did

In this phase, I worked on logging network activity so that I could observe DNS requests and firewall events generated by devices connected to my virtual router.

I used dnsmasq for DNS and DHCP logging and iptables for firewall logging.

## 1. DNS and DHCP Logging

I enabled DNS query logging and DHCP activity logging in `config/dns/dns.conf`.

The log file is:


/var/log/dnsmasq.log


This helps me observe DNS requests and DHCP activity from connected devices.

## 2. Firewall Logging

I created a custom chain called `VR_LOG` in the firewall configuration.

I added a rate limit of 5 log entries per minute to avoid generating too many log messages.

The logging rules are stored in:


config/logging/firewall-logging.v4


Firewall messages use the prefix:


VR-FIREWALL:


## 3. Testing

I connected my mobile phone to the virtual router and generated network activity.

I checked DNS activity using:


sudo tail -f /var/log/dnsmasq.log


I checked firewall messages using:


sudo dmesg | grep VR-FIREWALL


## 4. Observation

DNS logs showed requests from my connected mobile phone (`192.168.50.45`).

I observed DNS requests being forwarded to an upstream DNS server and responses being received.

I also found firewall log entries containing information such as:

- Incoming interface
- Source IP address
- Destination IP address
- Protocol
- Destination port

For example, some observed firewall entries showed traffic originating from `192.168.50.45`.

## Result

DNS and firewall logging were successfully configured and tested with traffic from an external device.

These logs help in observing network activity and understanding which traffic reaches the virtual router.
